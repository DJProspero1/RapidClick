# Product

## Register

product

## Users

Windows users automating repetitive clicking, testing software, and playing games. The user confirmed a general-purpose desktop utility, rather than a tool exclusively for gaming or testing.

## Product Purpose

RapidClick delivers fast, controllable mouse clicks. Success means the requested rate is delivered to Windows, exact limits are respected, stopping stays responsive, and users can distinguish input sent from input received by an application.

## Brand Personality

Clear, capable, familiar. The user specifically requested Google design throughout and dark mode. Follow Material-style hierarchy and familiar controls without implying Google affiliation.

## Anti-references

Avoid flashy gaming decoration, crowded legacy utility forms, and light surfaces that break the requested dark experience. Do not obscure stopping behind menus or advertise unmeasured speed.

## Design Principles

- Make starting and stopping immediately understandable.
- Keep the selected speed and mouse behavior visible together.
- Show real operating state and actionable failures.
- Prefer useful controls over decoration.
- Preserve keyboard operation and sensible defaults.

## Accessibility & Inclusion

Use readable contrast, labelled controls, visible keyboard focus, and text alongside state colors. Support Windows DPI scaling, window resizing, keyboard navigation, and scrolling in smaller windows. No decorative animation.
